# VibeKidbright IDE 3.7.2

อัปเดตการสร้างโค้ดคู่เฟิร์มแวร์/ซิม, Local Unity Simulator และแก้เส้นทางติดตั้ง/Build ESP-IDF บน macOS สำหรับบอร์ด KidBright32 แบบคลาสสิก

- สร้างและตรวจโปรแกรม C กับ JavaScript จากพฤติกรรมที่รองรับร่วมกัน ป้องกันการสร้างเฉพาะซิมโดยปล่อยเฟิร์มแวร์เป็น Hello scaffold
- ปรับ new-project isolation, การยืนยัน Keep/Undo และการโหลดไฟล์ซิมจากโปรเจกต์ พร้อมแสดงข้อผิดพลาดของ AI tool ให้ติดตามและแก้ไขต่อได้
- Local simulator รองรับ LED 16×8, ข้อความ/ตัวเลข/scroll, ปุ่ม, อุณหภูมิ/แสง, Digital/Analog IN1–4 ตาม profile, OUT/USB และ buzzer ตามขอบเขตที่ตรวจไว้ ไม่ใช่ตัวรัน ESP-IDF C/C++ ทั่วไปหรือ FreeRTOS/Wi-Fi emulator
- รักษา Build/Flash แยกจากซิม บันทึกไฟล์ dirty ให้สำเร็จก่อน Build และป้องกันการ Build ซ้ำซ้อน
- Mac ใช้ SDK/Python ที่ติดตั้งบน Mac จริง แยก Intel/Apple Silicon ตรวจ Python dependencies, CMake, Ninja และ compiler ก่อน Ready และไม่เรียก cmd.exe/export.bat
- Windows ยังคงชุดดาวน์โหลด/ติดตั้งเดิม เพิ่มการตรวจพื้นที่และตัวเลือกตำแหน่ง SDK ตามงานที่รวมอยู่ในรุ่นนี้

## ไฟล์ติดตั้งและการตรวจสอบ

CI ของ tag `v3.7.2` สร้าง Windows EXE/MSI และ macOS Universal DMG แล้วแนบใน Draft Release เดียวกัน โดยไม่เปลี่ยน Latest อัตโนมัติ การสร้าง DMG ต้องผ่าน native SDK/firmware checks บน Mac Intel และ Apple Silicon ก่อน ดูผลจริงใน Actions; ไม่ถือว่าผ่านจนกว่า job จะสำเร็จ

ผลตรวจ source ในเครื่อง Windows ก่อนส่งรีลีส: Rust 148 tests, frontend 148 tests, cargo check, TypeScript, frontend release build และ compiled UI/Unity probe ผ่าน การทดสอบ IPC ใช้ fixture ไม่ได้ Flash บอร์ดจริง และยังต้องทดสอบติดตั้ง/อัปเกรด/GUI/Flash บนเครื่องจริงทั้งสอง OS ก่อนเผยแพร่ให้ผู้ใช้ทั่วไป

หากไม่มี signing/notarization secrets ตัวติดตั้งอาจไม่มีลายเซ็นที่ระบบยอมรับ ผู้ดูแลควรตรวจ artifact และตั้งค่าการเซ็นให้ครบก่อน Publish
